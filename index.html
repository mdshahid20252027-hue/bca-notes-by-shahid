Operating System & Unix

Operating systems and Unix/Linux, explained from the ground up.

1. Introduction to Operating Systems

User / Application
↓
Operating System
↓
CPU • Memory • Storage • I/O Devices

An operating system (OS) is the main system software that manages computer hardware and provides a working environment for application programs. When you open a browser, save a file, print a document, or run a C program, the OS coordinates the hardware resources needed to complete the task. The OS acts as an intermediary between the user/applications and hardware. Its major responsibilities include process management, memory management, file management, device management, protection and security. A useful way to remember the relationship is: User → Application → Operating System → Hardware.

Key Points

  • OS as a resource manager
  • OS as a control program
  • System calls and OS services
  • Multiprogramming and time-sharing
  • Storage and I/O organization
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

2. Process Management

A process is a program in execution. A program is a passive set of instructions stored on storage; a process is the active execution of those instructions. The OS creates processes, schedules them, gives them CPU time, and releases their resources when they finish. A process normally moves through states such as New, Ready, Running, Waiting/Blocked and Terminated. The process control block (PCB) stores information required by the OS to manage a process, such as its state, program counter, CPU registers and scheduling information.

Key Points

  • Process states and state transitions
  • Process Control Block
  • Context switching
  • Threads
  • Inter-process communication
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

3. CPU Scheduling

CPU scheduling decides which ready process should receive the CPU next. Good scheduling attempts to keep the processor busy while reducing waiting and response time. Important criteria include CPU utilization, throughput, turnaround time, waiting time and response time. FCFS is simple but can suffer from the convoy effect. SJF chooses the shortest estimated CPU burst and can minimize average waiting time under suitable assumptions. Round Robin gives each process a time quantum and is commonly associated with interactive systems.

Key Points

  • FCFS
  • SJF and SRTF
  • Priority scheduling
  • Round Robin
  • Scheduling evaluation
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

4. Synchronization

User / Application
↓
Operating System
↓
CPU • Memory • Storage • I/O Devices

When multiple processes or threads share data, their operations can interfere with one another. A race condition occurs when the final result depends on the timing of concurrent operations. The critical-section problem asks how to ensure that shared data is accessed safely. A solution should provide mutual exclusion, progress and bounded waiting. Semaphores are synchronization primitives used to coordinate access to shared resources.

Key Points

  • Race condition
  • Critical section
  • Mutual exclusion
  • Semaphores
  • Classical synchronization problems
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

5. Deadlocks

A deadlock occurs when a group of processes is permanently waiting for resources held by one another. The four necessary conditions are mutual exclusion, hold and wait, no preemption and circular wait. An OS can handle deadlocks through prevention, avoidance, detection and recovery. Avoidance tries to keep the system in a safe state; the Banker's algorithm is a classic example.

Key Points

  • Four necessary conditions
  • Prevention
  • Avoidance and safe state
  • Detection
  • Recovery
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

6. Memory Management

Memory management controls how processes use main memory. The OS keeps track of which areas are free and which are occupied and translates logical addresses used by programs into physical addresses. Paging divides logical memory into fixed-size pages and physical memory into frames. Segmentation divides a program according to logical units such as code, data or stack. Virtual memory allows a process to use an address space larger than the currently available physical memory by moving pages between RAM and secondary storage.

Key Points

  • Logical vs physical address
  • Swapping
  • Paging
  • Segmentation
  • Virtual memory and demand paging
  • Page replacement and thrashing
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

7. Unix/Linux Fundamentals

Unix is a family of multiuser, multitasking operating systems. Linux is a Unix-like open-source operating system. A Unix/Linux environment commonly provides a shell through which users can execute commands and combine utilities. Common commands include pwd (current directory), ls (list files), cd (change directory), mkdir (create directory), cp (copy), mv (move/rename), rm (remove), cat (display/concatenate), grep (search text), ps (process information) and kill (send a signal to a process).

Key Points

  • File-system hierarchy
  • Users and groups
  • File and directory commands
  • Permissions: chmod, chown, chgrp
  • Processes and jobs
  • Pipes and redirection
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

8. vi, Shell and Administration

vi/vim is a modal text editor. Its basic modes are command mode, insert mode and command-line mode. Shells provide a command interface and can also run shell scripts. Redirection sends input or output to files. A pipe connects the output of one command to the input of another, for example `ls | grep txt`. Shell scripting combines commands, variables, conditions and loops to automate repetitive tasks.

Key Points

  • vi modes and navigation
  • Shell variables and PATH
  • Wildcards
  • Pipes and redirection
  • Shell scripts and awk
  • User accounts, backups and administration
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

Programming begins before code is written. First understand the problem, identify inputs and outputs, break the task into smaller steps, and define a precise algorithm. An algorithm is a finite sequence of unambiguous steps that transforms input into the desired output. A flowchart represents logic graphically, while pseudocode expresses the logic in structured natural language. Good problem solving also considers correctness, efficiency, edge cases and testing.

2. C Fundamentals

C is a compiled, general-purpose programming language widely used for systems programming and learning core programming concepts. A basic C program contains preprocessing directives, declarations, functions and statements. Variables store values in memory and every variable has a data type. Common basic types include int, char, float and double. Operators build expressions for arithmetic, comparison, logical decisions and assignment.

3. Control Statements

Control statements determine the order in which statements execute. Selection is used when a program must choose between alternatives; iteration repeats a block while a condition or loop rule allows it. `if`, `if-else` and `switch` handle decisions. `for`, `while` and `do-while` handle repetition. `break` exits a loop or switch, while `continue` skips to the next loop iteration. Nested control structures combine these ideas.

Key Points

  • switch
  • for, while, do-while
  • Nested loops
  • break and continue
  • goto and comma operator

5. Arrays and Strings

An array stores multiple values of the same type in contiguous memory locations. A one-dimensional array can represent a list; a two-dimensional array can represent a table or matrix. A C string is a sequence of characters terminated by the null character `\0`. Common string operations are provided by the standard library, but the programmer must always consider array size and termination to avoid invalid memory access.

6. Structures, Unions and Bitwise Operations

A structure groups related values that may have different data types under one name. A union also groups different members, but its members share the same memory area, so only one member's stored value is meaningfully active at a time. Bitwise operators work directly on individual bits. They are useful in low-level programming, flags and compact data representations.

Key Points

7. Pointers

A pointer is a variable that stores a memory address. The address-of operator `&` obtains an address and the dereference operator `*` accesses the value at that address. Pointers make it possible to modify caller data through functions, work efficiently with arrays and build dynamic data structures. Pointer arithmetic depends on the pointed-to type; adding one advances by the size of that type.

Key Points

  • Pointer declaration
  • Address and dereference
  • Pointer arithmetic
  • Pointers and arrays
  • Arrays of pointers
  • Structures and pointers
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.

8. File Handling and Preprocessor

File handling allows a C program to store data beyond the lifetime of a running program. A file is opened with a mode such as read, write or append, processed, and then closed. The preprocessor runs before compilation. Directives such as `#include`, `#define`, `#ifdef` and `#endif` support header inclusion, macros and conditional compilation.

Key Points

Mathematics (Numerical Techniques)

Numerical methods with concepts, formulas, worked examples and exam-oriented procedure.

Numerical methods work with approximations, so understanding error is essential. If the true value is x and the approximate value is xₐ, the absolute error is |x − xₐ|. Relative error compares the absolute error with the magnitude of the true value; percentage error is relative error multiplied by 100. Accuracy and precision are related but different: accuracy concerns closeness to the true value, while precision concerns consistency or resolution of measurements.

2. Roots of Equations

A root of f(x)=0 is a value of x for which the function becomes zero. Numerical root-finding is useful when an algebraic equation cannot be solved conveniently in closed form. Bisection starts with an interval [a,b] where f(a) and f(b) have opposite signs. It repeatedly takes the midpoint and keeps the half-interval that still brackets a root. Newton-Raphson uses the tangent-line idea: xₙ₊₁ = xₙ − f(xₙ)/f′(xₙ).

Key Points

3. Interpolation and Finite Differences

Interpolation estimates an unknown value inside the range of known data. For equally spaced data, finite differences organize changes between successive values. Forward differences are convenient near the beginning of a table, backward differences near the end, and central-difference formulas near the middle. Difference tables also help check whether the tabulated data behaves like a polynomial of a particular degree.

Key Points

  • Forward differences
  • Backward differences

5. Numerical Differentiation and Integration

Numerical differentiation estimates derivatives from tabulated or approximate values. Numerical integration estimates the area under a curve when an exact integral is inconvenient. The trapezoidal rule replaces small pieces of the curve by trapezoids. Simpson's 1/3 and 3/8 rules use polynomial approximations and can give better accuracy for sufficiently smooth functions when their spacing requirements are satisfied.

6. Linear Systems — Direct Methods

A system of simultaneous linear equations can be written as AX=B. Direct methods transform the system into a form from which the unknowns can be obtained. Gaussian elimination uses elementary row operations to produce an upper-triangular system followed by back substitution. Gauss-Jordan continues elimination until a reduced form is obtained. Factorization methods split the coefficient matrix into simpler factors.

Key Points

  • Gauss elimination
  • Gauss-Jordan
  • Factorization
  • Ill-conditioned systems
  • Back substitution

7. Linear Systems — Iterative Methods

Iterative methods begin with an initial approximation and repeatedly improve it. Jacobi computes new values from the previous iteration; Gauss-Seidel uses newly computed values immediately within the same iteration. Convergence depends on properties of the system and the chosen starting values. A stopping rule is needed, such as requiring successive approximations to differ by less than a chosen tolerance.

Key Points

  • Gauss-Jacobi

  • Convergence
  • Stopping criteria
  • Iteration tables

8. Ordinary Differential Equations

Numerical methods approximate solutions of differential equations when an exact solution is difficult or unnecessary. Euler's method uses the slope at the current point to move to the next point. Modified Euler improves the basic estimate by using additional slope information. Runge-Kutta methods use several slope evaluations within a step; the fourth-order method is widely used because it offers good accuracy without requiring higher derivatives.

Key Points

  • Taylor series method
  • Euler method
  • Modified Euler
  • RK2
  • RK4
  • Step-size selection
Exam Focus: Define the concept, explain its purpose, give a suitable example, and compare it with related concepts where applicable.
